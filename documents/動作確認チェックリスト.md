## 5. エラー表示（新機能 v1.3.0）

新しい `.jsh` ファイルに、次のコードを貼り付けて確認してください。

```java
class Test{
    String bbbb = null;

    Test(String str){
        bbbb = str;
    }

    void ssssss(){
        System.out.println(bbbb);
    }
}

Test test = new Test(1111);
test.ssssss();
```

| # | 確認内容 | 期待する結果 | 結果 | 気づいた点 |
|---|----------|--------------|------|-----------|
| 5-1 | 上のコードを貼り付けて少し待つ | `Test test = new Test(1111);` の `1111` に**赤い波線**が出る | | |
| 5-2 | 波線にマウスを重ねる | 「不適合な型: intをjava.lang.Stringに変換できません」と**日本語**で表示される | | |
| 5-3 | 次の行 `test.ssssss();` を確認する | **赤線が出ない**（原因の行だけに出る） | | |
| 5-4 | 「問題」パネルを開く（Ctrl+Shift+M） | エラーが1件表示される（出どころ：JShell） | | |
| 5-5 | `1111` を `"1111"` に直す | 約0.5秒後に赤線が消える | | |
| 5-6 | 行末の `;` を1つ消す | 「';'がありません」の赤線が出る。戻すと消える | | |
| 5-7 | `Scanner sc = new Scanner(System.in);` や `String s = input();` を書く | **エラーにならない**（実行時と同じく import と便利メソッドが使える） | | |
| 5-8 | コード中（文字列の外）に全角スペースを入れる | エラーにならない（実行時と同じく半角として扱う） | | |
| 5-9 | `while (true) { }` や `String s = input();` を含むファイルを開いたまま編集する | 固まらない・入力待ちにならない（**コードは実行されない**） | | |
| 5-10 | 存在しないメソッドを呼び出す（例：メソッドの中で `bar();`） | `bar` に「シンボルを見つけられません」の赤線が出る | | |
| 5-11 | 波括弧 `}` を1つ消す | 「構文解析中にファイルの終わりに移りました」の赤線が出る | | |
| 5-12 | 初回（VS Code 起動直後）の表示までの時間 | 数秒以内に赤線が出る（ヘルパーの起動を含むため） | | |
| 5-13 | エラー表示中に補完（4-1）も使う | 補完も通常どおり動く | | |
| 5-14 | 設定で `Enable diagnostics` をオフにする | 赤線が消え、以降も出ない | | |
| 5-15 | 設定を戻す | 再び赤線が出る | | |
| 5-16 | ファイルを閉じる | 「問題」パネルからそのファイルのエラーが消える | | |

## 7. 問題が起きたときに確認・共有していただきたい情報

うまく動かない場合、以下をお知らせいただけると原因を特定しやすくなります。

| 情報 | 取得方法 |
|------|----------|
| エラーメッセージの全文 | 画面右下に出る通知の文言 |
| 拡張機能のログ | メニュー「ヘルプ」→「開発者ツールの切り替え」→ Console タブの赤い行 |
| 実行時のコマンド | 「Run JavaCode」で開いたターミナルに表示されるコマンド行 |
| 使用している Java | 設定 `java_home` の値。空なら同梱Javaを使用 |
| 再現手順 | どのファイルで、どの操作をしたか |

### つまずきやすい点

| 症状 | 考えられる原因 |
|------|----------------|
| 補完の候補が出ない | 初回のヘルパー起動中（数秒待つ）／`Enable completion` がオフ／Java が使えない |
| 赤線が出ない | 初回のヘルパー起動中（数秒待つ）／`Enable diagnostics` がオフ／Java が使えない／ファイルの言語モードが Java でない |
| 整形しても何も起きない | 既に整形済み／文法エラーがある（この場合はエラーメッセージが出ます） |
| 「Run JavaCode」がメニューに出ない | ファイルの言語モードが Java になっていない（右下の表示を確認） |
| Windows以外で動かない | `java_home` の設定が必要（同梱Javaは Windows 用のみ） |
