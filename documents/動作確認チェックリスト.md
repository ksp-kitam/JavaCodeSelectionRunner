## 6. 問題が起きたときに確認・共有していただきたい情報

うまく動かない場合、以下をお知らせいただけると原因を特定しやすくなります。

| 情報 | 取得方法 |
|------|----------|
| エラーメッセージの全文 | 画面右下に出る通知の文言 |
| 拡張機能のログ | メニュー「ヘルプ」→「開発者ツールの切り替え」→ Console タブの赤い行 |
| 実行時のコマンド | 「Run JavaCode」で開いたターミナルに表示されるコマンド行 |
| 使用している Java | 設定 `java_home` の値。空なら同梱Javaを使用 |
| 再現手順 | どのファイルで、どの操作をしたか |

### つまずきやすい点

| 症状 | 考えられる原因 |
|------|----------------|
| 補完の候補が出ない | 初回のヘルパー起動中（数秒待つ）／`Enable completion` がオフ／Java が使えない |
| 整形しても何も起きない | 既に整形済み／文法エラーがある（この場合はエラーメッセージが出ます） |
| 「Run JavaCode」がメニューに出ない | ファイルの言語モードが Java になっていない（右下の表示を確認） |
| Windows以外で動かない | `java_home` の設定が必要（同梱Javaは Windows 用のみ） |
